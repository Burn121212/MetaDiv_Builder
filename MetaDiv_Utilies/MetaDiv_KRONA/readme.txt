# MetaDiv_KRONA is a standalone utility for converting MetaDiv-compatible CSV tables into interactive Krona-style hierarchical charts.

# It is designed especially for visualizing taxonomic or ecological subsets extracted from a MetaDiv FINAL_DB, but it can also work with other compatible CSV tables containing taxonomic ranks and abundance data.

# The notebook generates both:

# Krona-compatible tab-delimited .txt tables

# self-contained interactive .html visualizations

# The HTML files are generated directly from Python and can be opened locally in a web browser.

# No KronaTools, ktImportText, Excel, Docker, or internet connection is required to generate the HTML charts.
